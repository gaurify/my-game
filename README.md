# Dodge the Blocks

A simple browser game made with **HTML, CSS, and JavaScript**.  
Move left and right to dodge falling blocks and try to beat your best score.

## Features
- Clean, beginner-friendly code
- Score and best score tracking
- Restart / replay support
- Keyboard controls
- Mobile controls
- Ready for GitHub Pages

## Controls
- **Left Arrow** or **A** = move left
- **Right Arrow** or **D** = move right
- **Enter / Space** = start game
- **Esc** = reset game

## Run locally
Just open `index.html` in your browser.

If you want a local server, you can use one of these:
- VS Code Live Server
- Python: `python -m http.server`
- Node: `npx serve`

## Deploy to GitHub Pages
1. Push these files to your GitHub repository.
2. Go to **Repository Settings**.
3. Click **Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save.
6. Wait for GitHub to publish your site.

Your game will be available at a URL like:

`https://gaurify.github.io/my-game/`

## Notes
You can easily customize:
- block speed
- player size
- colors
- scoring
- difficulty curve
